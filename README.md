# Saudi Retail & E-commerce Analytics Portfolio

An interactive, responsive data analytics portfolio and web showcase built to present a deep Business Intelligence study on the Saudi retail sector. The platform evaluates and simulates the digital transformation, financial performance, and e-commerce adoption of 6 major listed Saudi corporations (Jarir, Nahdi, Cenomi Retail, Alsaif Gallery, Al Majed Oud, and SACO) from 2022 to 2025.

## 🌐 Live Portfolio Showcase
👉 **[View the Live Website & Interactive Dashboard](https://zesty-pothos-487471.netlify.app/)**

---

## 💻 Tech Stack
* **Frontend Showcase:** HTML5, CSS3, Bootstrap 5, JavaScript (Dynamic Bilingual Translation: Arabic/English).
* **Business Intelligence & Analytics:** Power BI Desktop & Service, DAX, Predictive Analytics (What-If Modeling).
* **Hosting & Deployment:** Netlify (Continuous Deployment).

---

## 🚀 Portfolio Core Sections
1. **Interactive Dashboard Live View:** Features an embedded Power BI dashboard utilizing custom star-schema data models, dynamic KPIs, and automated regional data formatting ($bn/M scales).
2. **Predictive Simulation Engine:** Includes a dynamic forecasting simulator allowing stakeholders to stress-test future e-commerce target growth rates and revenue shares.
3. **Strategic Market Insights:** Provides multi-year financial baseline evaluations and comprehensive digital maturity indexing.
